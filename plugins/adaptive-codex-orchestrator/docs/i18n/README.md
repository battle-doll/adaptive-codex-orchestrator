# Localization index

Adaptive Codex Orchestrator public documentation is proposed in five
languages. English source documents remain canonical when a translation and
the maintained source differ. Technical identifiers, commands, URLs, the
`MIT License` name, and the non-affiliation and warranty meaning are not
localized into different claims.

The project currently recognizes deterministic control commands in Korean and
English only. Translated documentation does not imply additional command-
language support. The untranslated [MIT License](../../LICENSE), maintained
[Terms](../TERMS.md), [Security](../SECURITY.md), and [Privacy](../PRIVACY.md)
remain the authoritative legal, security, and privacy texts. The concise English
companions and translations point back to those detailed sources.
